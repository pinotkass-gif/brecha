# Brecha

Simulador cambiario personal: oficial, blue, MEP, CCL y cripto. **Sólo simulación**: no ejecuta operaciones ni se conecta a cuentas.

Abrila en https://pinotkass-gif.github.io/brecha/

Los datos que cargás quedan sólo en tu navegador. Cotizaciones de referencia de [DolarAPI](https://dolarapi.com) (sin afiliación).
Incluye [big.js](https://github.com/MikeMcl/big.js) (licencia MIT, aviso dentro de `src/vendor/big.mjs`).
